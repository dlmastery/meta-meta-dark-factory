# Debate Protocol

Use these rounds:

1. Context prime: load only relevant requirements, artifacts, code, decisions, risks, control graph node, and work-ledger item.
2. Independent proposals: each expert proposes solution, assumptions, risks, and evidence needed before seeing other proposals.
3. Cross critique: each expert critiques the other proposals and records failed assumptions.
4. Alternative synthesis: moderator creates at least 2 viable alternatives and a recommendation.
5. Decision vote: accept, revise, reject, split, defer, or escalate.
6. Verification plan: define how the decision will be proven.
7. Certificate: record evidence, score, dissent, rejected alternatives, residual risk, and re-entry triggers.

After 3 failed loops, escalate to the human owner.

Every debate must be preserved as a governed record and linked to traceability before the node can close.
