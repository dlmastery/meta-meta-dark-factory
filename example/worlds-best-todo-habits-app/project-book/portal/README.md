# Northstar Daily Human Review Portal

**NO AI SLOP ALLOWED AT ALL - ZERO TOLERANCE TO SLOP AND HALLUCINATIONS**

Open `index.html` in a browser to review the project book through a human-facing dashboard.

The portal is static and local-first. It links to Markdown documentation, structured records, evidence files, screenshots, gates, certificates, code, tests, and Mermaid diagrams. The machine-readable index is `portal-data.json`, and the diagram atlas is `diagrams.md`.

This portal is a review surface, not the source of truth. The source of truth remains the project book, records, evidence files, source code, tests, and installed dark-factory skill rules.
