# Northstar Daily

**NO AI SLOP ALLOWED AT ALL - ZERO TOLERANCE TO SLOP AND HALLUCINATIONS**

Northstar Daily is the example app for the dark-factory meta-skill system. It combines a fast todo command center, habit behavior design, daily planning, focus mode, and shutdown review in a single static browser app.

Open `app/index.html` in a browser. The app uses local storage and needs no build step.

## What This Example Demonstrates

- Product-tailored meta-meta factory run instead of a generic checklist.
- Intake, decomposition, research, PRD, architecture, test strategy, implementation, scenario testing, WYSIWYG testing, traceability, expert review, and Hawkeye conformance.
- A working app, not just documents.
- Local automated tests:
  - `node tests/core.test.cjs`
  - `node tests/browser-wysiwyg.test.cjs`

## Product Capabilities

- Quick add parser for natural task capture with priority, date, estimate, and tags.
- Today, upcoming, and inbox task views.
- Daily workload guard based on planned minutes versus capacity.
- Eisenhower-style priority matrix.
- Timeboxed day sequence.
- Habit tracker using cue, tiny action, motivation, ability, and prompt scores.
- Focus mode for one active task.
- Shutdown notes and local export.
